# sponsorbot-assets

Images the sponsorship bot references by raw URL. This repo is public only so Discord can fetch them.

- `spacer.png`: a 1200x1 fully transparent PNG. Every Discord card carries it in a MediaGallery so all cards render at full width (hooov/sponsorbot#34).
- `status-*.png`: status icons (green check ok, orange clock waiting, red exclamation problem). Tried on the status card and removed; kept for reference.
